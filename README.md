# AI Video Maker

A mobile-first AI video creation project for generating real motion promo videos and, later, cinematic short-film scenes from a story, logo, app screens, images, and voice.

## Target

- Promo Mode: logo + app screenshots/screen recordings + features -> professional animated promo video
- AI Film Mode: story -> scene plan -> AI-generated moving clips -> voice/music/subtitles -> final MP4
- 9:16 and 16:9 output
- Tamil/English support
- Mobile-first workflow

## Planned stack

- Next.js + React
- Remotion for timeline/composition rendering
- FFmpeg for media processing
- Optional AI video backends (self-hosted/open-source or API)
- Optional TTS for Tamil/English voiceover

Initial project setup in progress.
